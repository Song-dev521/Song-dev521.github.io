善假于物：我在 GitHub 上挖到的开源宝藏
一份关于"免费、开源、真香"的私人工具清单

📅 2026年10月11日 📖 阅读约 8 分钟 # 开源 · 工具分享

写在前面：荀子说"君子生非异也，善假于物也"。这段时间逛 GitHub，陆陆续续捡到一些好东西——有的帮我省下大把重复劳动，有的让页面从"能用"变得"好看"。挑了九个自己真正在用、也真心觉得好的，整理成这份清单，分享给你。

我一直觉得，好的工具不该只是"能跑"，而是那种用完之后会忍不住想"早该遇到你"的东西。下面这些项目，一半是提升日常效率的实用软件，一半是让前端页面脱胎换骨的美学弹药库。全部开源、免费，而且都还在活跃更新。

一、效率工具：把电脑用得更顺手

🗂️ 1. Filee —— 拖一下，什么格式都能转

格式转换是个高频又别扭的需求：装 Office 全家桶太重，用在线网站又担心文件被上传。Filee 的解法很干脆——全部在本地完成，一个文件都不上传。

它是韩国开发者 KnifeLemon 用 C# / .NET 10 + Avalonia 写的开源转换工具（MIT 协议），支持图片、PDF、Word、Excel、PPT、HWP、音视频、电子书等 17 大类、两百多种格式。最妙的交互是：在文件管理器里按住 Ctrl（macOS 是 Option）拖住文件，光标旁会弹出一个"格式圆环"，松手就转换完成，结果直接落在原文件旁边。

除了拖拽，它也提供命令行，适合批量处理和自动化：

# 单文件转换
filee convert photo.heic --to jpg

# 批量转换并指定质量
filee convert *.png --to webp --quality 80 -o converted

# 监听文件夹：扔进去什么就转什么
filee watch D:\Inbox --to pdf --move-originals

它底层靠 FFmpeg、LibreOffice、Calibre、Pandoc 等引擎"分层"工作，需要时按需下载。目前 Windows 是正式版，macOS 和 Linux 是预览版。项目很新（2026 年 9 月建仓），迭代飞快——这也意味着边角 bug 会多一些，转换复杂文档建议人工过一眼版式。

🌐 2. OCS Desktop —— 浏览器多开与自动化神器

OCS Desktop（ocsjs/ocs-desktop）是 OCS 生态的桌面端，基于 Electron + Vue 3 + TypeScript 构建。它把用户脚本、浏览器管理、多账号操作整合到一个客户端里：一键启动脚本、浏览器多开/分身、自动登录、多账号批处理……跨平台支持 Windows / Linux / macOS。

技术上有个很聪明的设计：它不内置 Chromium，而是复用你电脑上已有的本地浏览器，所以打包体积能压得很小。开发也简单：

corepack enable
pnpm install
pnpm dev        # 同时启动 Web 界面与 Electron 主进程
pnpm build      # 打包

它最适合"需要重复执行浏览器操作"的场景。当然，功能强也意味着要用在合规的地方——用来自动化自己的重复工作流很香，别拿它去做违反平台规则的事。

📱 3. LocalSend —— 跨平台的"隔空投送"

苹果有 AirDrop，但跨系统传个文件总让人头疼。LocalSend 就是那个"全平台通用版 AirDrop"：Windows、macOS、Linux、Android、iOS 都能用，不需要联网、不需要账号、不需要服务器，文件只在你的局域网里跑。

它用 REST API + HTTPS 通信，TLS 证书在每台设备上临时生成，还支持 PIN 验证，做到端到端加密。传输走 Wi-Fi 满速，没有带宽限制，也没有广告和追踪。安装后同一网络下自动发现附近设备，点一下就发。

和 Filee 一样，LocalSend 的"底气"也是三个字：不上传。在隐私越来越值钱的今天，这本身就是核心功能。

二、前端美学：让页面从"能用"到"好看"

下面这组是我做前端时反复打开的"灵感弹药库"。它们的共同点是：代码是复制进你项目的，属于你自己，而不是被锁在某个 npm 依赖里。

✨ 4. Motion —— 会动的界面才有灵魂

Motion（motion.dev，前身就是大名鼎鼎的 Framer Motion）是 React / Vue / 原生 JS 生态里最受欢迎的动画库之一，GitHub 三万多星，MIT 协议。它把动效当成一种"交互语言"而不是装饰：弹簧物理、手势（hover / tap / drag）、布局动画、滚动联动，甚至元素离开 DOM 的退场动画都能优雅处理。

// npm install motion
import { animate, stagger, inView } from "motion";

// 弹簧动画：CSS 做不出来的手感
animate(".box", { scale: 1.2, rotate: 10 }, { type: "spring", stiffness: 300, damping: 15 });

// 滚动进入视口时触发
inView(".section", (el) => animate(el, { opacity: 1, y: 0 }));

它分两个体积版本：mini 版只有约 2.6kb（走浏览器原生 Web Animations API），完整版约 18kb，还支持 tree-shaking。这里也顺带记一份我自己常用的动效参数规范——好的动效靠的不是"感觉"，而是统一的时长与缓动：

  • 时长：微交互（hover / 图标）150ms，常规过渡 200ms，结构变化（抽屉 / 折叠）300ms，页面入场 400–600ms；单个动画别超过 800ms。
  • 缓动：进入用 cubic-bezier(0.16,1,0.3,1)，退出更快，位移用 cubic-bezier(0.4,0,0.2,1)，循环才用 linear。
  • 降级：一定要处理 prefers-reduced-motion，这是对用户的尊重。

🧩 5. React Bits —— 复制粘贴就能用的动效组件

如果说 Motion 是"引擎"，那 React Bits 就是一整箱"成品零件"。它号称是最大、最有创造力的 React 动画组件库，215 个免费组件，分成文字动画、动画效果、交互组件、微交互、背景特效五大类。粒子汇聚成照片、文字逐字拼装、鼠标跟随的光晕……这些你从零写要两天的东西，这里直接给你源码。

每个组件都有四种版本（JS / TS × CSS / Tailwind），通过 shadcn CLI 一行命令装进项目，装的是源码，不是依赖——装完就能改，改完就是你的：

npx shadcn@latest add @react-bits/SplitText-TS-TW
npx shadcn@latest add @react-bits/Aurora-TS-TW

还有 Background Studio、Shape Magic 等五个在线可视化工具，可以边调边导出代码。Vue 和 Svelte 也有官方移植版（Vue Bits / Svelte Bits）。

🎨 6. Uiverse —— 全世界最大的开源 UI 元素库

Uiverse 是一个社区驱动的开源 UI 元素库，七千多个元素，100% 免费可商用，三十多万贡献者。按钮、加载动画、输入框、玻璃拟态卡片、Tooltip……日常用到的小控件几乎都能在这里找到。

它的用法极简：搜到你想要的元素 → 选 HTML/CSS、Tailwind、React 或 Figma → 复制粘贴 → 只改颜色、圆角、动效时长这三样，结构别动，最快也最不容易翻车。如果粘贴后样式乱了，多半是项目没引 Tailwind 或 CSS 作用域冲突，改用纯 HTML/CSS 版本即可绕开。

🌌 7. Aceternity UI —— Tailwind 界的"视觉魔法"

Aceternity UI 是 Tailwind CSS + Framer Motion 的动画组件集，70 多个组件，主打"抄进来就会动"：3D 倾斜卡片、跟随鼠标的聚光灯、背景光束、流动边框、波浪背景、Mac 风格 Dock……很多效果你都在 Linear、Vercel、Clerk 这些网站见过。

它同样走 shadcn registry 的路子，代码直接落到 components/ui/，没有任何运行时依赖：

npx shadcn@latest init
npx shadcn@latest add @aceternity/3d-card
npx shadcn@latest add @aceternity/background-beams
npx shadcn@latest add @aceternity/spotlight

注意有些组件（比如 Spotlight）需要你在 Tailwind 配置里补一段 keyframes，文档写得很清楚，照着加就行。免费版已经足够撑起一个漂亮的个人站，Pro 是可选的付费增强。

🧱 8. shadcn/ui —— 组件不属于库，而属于你自己

上面两个组件库都基于同一个理念，源头就是 shadcn/ui。它严格来说"不是一个组件库"，而是一组你可以复制到项目里的组件集合，底层用 Radix UI 保证无障碍、用 Tailwind 做样式。

它的颠覆性在于：没有 npm 依赖，组件源码直接进你的仓库，你怎么改都行。这种"代码归你"的模式现在几乎成了新一代组件库的标准，React Bits、Aceternity 都是它的信徒。还没用过的强烈建议从它入门：

npx shadcn@latest init
npx shadcn@latest add button card dialog

🔣 9. Lucide —— 图标界的"万能通用语"

最后一个补一个"小而美"的：Lucide 是我用过最顺手的开源图标库，一千多个统一线条风格的 SVG 图标，支持 React / Vue / Svelte 等几乎所有框架，按需引入、可改颜色和粗细，tree-shaking 友好。它是我每个前端项目的标配——图标这种细节统一了，整个界面的"精致感"立刻就上来了。

npm install lucide-react
// import { House, Search, Settings } from "lucide-react"

写在最后

整理完才发现，这九个工具有一条共同的暗线：它们都把选择权和所有权还给了使用者——文件不上传、代码复制进你自己的仓库、参数随便改。这大概就是开源最迷人的地方：它不只是"免费"，更是"自由"。

如果你也在囤工具，我的三条小心得：

  1. 别囤，先用起来。 收藏夹里的 100 个仓库不如真正跑起来的 1 个。
  2. 先读 README 再看 License。 尤其商用时，Commons Clause 这类条款要看清楚。
  3. 用好了顺手点个 Star。 那是开发者继续维护下去的动力。

善假于物，而不是困于物。 工具的价值，终究在于你用它做出了什么。🛠️
